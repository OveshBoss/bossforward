### ⚡ Overview
An ultra-fast, asynchronous, multi-threaded Telegram message forwarding automation bot. Built on top of the modern Pyrogram architecture to mirror, sync, and migrate content between public and private channels with zero latency. 

> **🤖 AI Engine Feature:** Automatically scans database checkpoints and safely recovers/restarts all interrupted user forwarding tasks instantly if the server restarts.

---

## 🚀 Key Features

- [x] **⚡ Public Forwarding Engine:** Highly optimized background streams using multi-worker bots.
- [x] **🔒 Private Mirroring Protocol:** Seamless userbot integration to sync private/restricted chats.
- [x] **✍️ Dynamic Meta Customizer:** Full support for custom text captions, HTML layouts, and custom Inline Markups.
- [x] **🎯 Smart Skip Controls:** Automatically drops duplicate entries to keep target channels clean.
- [x] **🛡️ Advanced Granular Filters:** Filter content streams selectively based on extension types, strict keywords, file sizes, and structural parameters.
- [x] **📊 Real-Time AI Status Hub:** Live percentage tracking, speed calculations (msgs/sec), and countdown timers (ETA) with manual refresh triggers.
- [x] **🌀 Auto Recovery Mode:** 100% crash-proof tracking using persistent system checkpoints.

## 🛠️ Available Commands

### 👤 User Commands
* `/start` - Check system pulse and connection status.
* `/forward` - Initiate the interactive forwarding wizard setup.
* `/settings` - Configure custom captions, extensions, and filtering preferences.
* `/unequify` - Deep scan and clear duplicate media components from the current active chat.
* `/stop` - Instantly abort and terminate your ongoing system tasks.
* `/reset` - Revert user configurations back to factory/system defaults.

### 👑 Administration Suite (Owner Only)
* `/restart` - Safely flush buffers and cold-reboot the core engine server.
* `/resetall` - Wipe configurations for all users globally.
* `/broadcast` - Push an absolute network-wide announcement notification to all registered users.

## 📐 System Variables Configuration

| Variable Name | Description | Source / Requirement |
| :--- | :--- | :--- |
| `API_ID` | Telegram Core Application Numeric ID | Obtain via [my.telegram.org](https://my.telegram.org) |
| `API_HASH` | Secure Alphanumeric Application Hash Token | Obtain via [my.telegram.org](https://my.telegram.org) |
| `BOT_TOKEN` | Core Gateway Access Authentication String | Create & fetch via [@BotFather](https://t.me/BotFather) |
| `BOT_OWNER` | Unique Telegram Account Numeric Identifier of Administrator | Retrieve via auditing bots like `@Userinfobot` |
| `DATABASE_URI` | Cloud Distributed Storage Connection String Instance | Setup a dedicated tier cluster via [MongoDB Atlas](https://mongodb.com) |
| `BOT_SESSION` | Custom identifier name string for local system databases | Set any string (e.g., `ovesh_forward_bot`) |
| `DATABASE_NAME` | Dedicated schema cluster collection database workspace name | Define a personal database title identifier |
